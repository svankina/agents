## Local GitLab

Read `~/NOTES.md` for local Pi installation/update details and local GitLab
server coordinates before re-investigating them.

When asked to add a GitLab remote for a local project, use the local GitLab
instance as the canonical internal remote. Default remote name: `gitlab`.
Default SSH URL pattern: `ssh://git@localhost:2222/root/<repo>.git`.
